# spaCy Skill Extraction

## Objective
Extract technical and soft skills from text using spaCy with rule-based logic and PhraseMatcher.

## Tools Used
- Python
- spaCy
- PhraseMatcher

## Features
- Case-insensitive technical skill extraction
- Soft skill extraction using token comparison
- Duplicate removal and normalization
- JSON formatted output

## How to Run
```bash
pip install spacy
python -m spacy download en_core_web_sm
python skill_extraction.py

Sample Output:
{
  "technical_skills": ["python", "sql", "nlp"],
  "soft_skills": ["communication", "teamwork"]
}
